### 🚀 About Me

Hey there! 👋 I am **Mohd Jawwad**, a developer focused on **Python, FastAPI, and Generative AI**. I build robust backend APIs, production-ready RAG pipelines, and intelligent LLM-driven applications.

- 🤖 **GenAI & RAG:** Building end-to-end RAG pipelines, dense vector search with **Qdrant** and **Sentence-Transformers**, multi-tool LLM workflows (**Groq**, **Google Gemini**), and strict schema validation with **Pydantic**.
- ⚡ **Backend & Systems:** Designing high-performance REST APIs with **Python** & **FastAPI**, creating low-level primitives from scratch (like custom **Token Bucket** rate limiters), and building asynchronous services.
- 🌐 **Full-Stack Development:** Shipping modern web applications using **Next.js**, **TypeScript**, **Supabase**, and **Tailwind CSS**.
- 🛠️ **Engineering Philosophy:** Deeply curious about how systems operate under the hood—building core components from first principles to ensure performance and reliability.
